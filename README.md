# Antigravity Japanese Localization Mod

Google Antigravity 2.0 (Windowsデスクトップ版) のUIを日本語化するパッチModです。

## 特徴

- **包括的な日本語ローカライズ**: メニューバー、サイドバー、操作ボタン、設定画面の全タブ、マウスオーバー時のツールチップ、ドロップダウンメニューの選択肢と説明文まで日本語化します。
- **安全設計**: チャットの会話本文やコードブロック、入力中テキストは翻訳から除外され、保護されます。
- **簡単インストール**: `install.bat` をダブルクリックして実行するだけで適用できます。
- **自動バックアップ & ワンクリック復元**: パッチ適用時に元の状態が自動バックアップされ、`uninstall.bat` でいつでも元の英語状態に戻せます。
- **アップデート対応**: Antigravity本体がアップデートされた際も、`install.bat` を再実行するだけで最新バージョンに再適用されます。

## 必要要件

- Windows 10 / 11
- Google Antigravity 2.0 (Windows版)
- Node.js (v18以上推奨)

## 使い方

### インストール (日本語化)
1. 本リポジトリのコードをダウンロードまたはクローンします。
2. フォルダ内の `install.bat` をダブルクリックして実行します。
3. 自動でAntigravityが再起動し、日本語化されたUIで立ち上がります。

### アンインストール (元の英語に戻す)
1. フォルダ内の `uninstall.bat` をダブルクリックして実行します。
2. バックアップから元のファイルが復元され、Antigravityが再起動します。

### Antigravity本体がバージョンアップした場合
Antigravity本体の更新が入ると公式の英語状態に戻りますが、再度 `install.bat` を実行するだけで最新版に日本語化が適用されます。

## ファイル構成

- `install.bat`: インストール用バッチファイル
- `uninstall.bat`: 復元・アンインストール用バッチファイル
- `install-mod.js`: パッチ構築および適用スクリプト
- `restore-mod.js`: 復元スクリプト
- `jp-dict.json`: 日英翻訳辞書
- `jp-mod-renderer.js`: レンダラー用動的翻訳エンジン
- `menu-patch-snippet.js`: メインメニュー翻訳スニペット
